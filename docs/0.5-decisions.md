## 留给负责人的

1. 前沿模型谁付钱（用户 key / Anthropic 后端 / DeskMind 代理）。夜里只用了 YY 和 OpenRouter 做开发。
2. Node 固定 22 还是 24。
3. README 的「全部用本机小模型」改成什么说法（我先改成「本地优先，前沿模型可选」）。
4. 凭证的 `rule` 档：持久化在哪、用户在 app 里怎么查看和撤销。
5. D20：用户窗口里只改视图状态（选中一行、切标签页）要不要降为不用同意。现在按最严的算。
6. 真机：夜里屏幕一直锁着（前台 loginwindow），真机的界面任务没跑成；锁屏那条验收（0.25 s 内以 environment 结束、不调模型）在真机上过了。解锁后跑：`echo '{"raw":"…","scope":"/tmp/dm-real","config":"yy-luna","driver":"hands"}' | pnpm app app-run`。

## 没做的（照计划里的清单）

- 编排器（本地配置）的异步化、界面步骤进计划、界面核对、回答出口：前沿配置由新的运行时覆盖了这四样；本地配置的编排器留到试验二有数据再动。
- 卡片文字跟随语言（D18）。
- 运行时这条路的撤回（D19）。
- 试验二（本地模型做理解和计划）、试验三（凭证交互规格）没做；凭证的机制和三档范围已经实现（D4、D5），规格文档可以从代码和测试里抽。
- hands 的 `executor.py` 只在锁屏状态下验证过 snapshot、open_window；observe / act 的真机路径没验证。
